How it works

One command. Fully ranked selects.

VisionCull runs the full pipeline locally — no model downloads, no API keys, no internet connection required.

1

Scan & score

Every image is scored for aesthetic quality using VNCalculateImageAestheticsScoresRequest on the Neural Engine. Composition, lighting, visual appeal — evaluated in ~10ms per image on warm hardware.

2

Cluster duplicates

Feature vectors from VNGenerateImageFeaturePrintRequest are compared via cosine distance. Near-identical shots are grouped; only the highest-scoring image from each cluster advances.

3

Rank & select

Surviving images are ranked by aesthetic score, filtered by classification labels if requested, and the top N are copied to your output folder — named and ranked.

Features

Everything the Neural Engine already knows.

Built on Vision framework APIs that ship with macOS — no model downloads, no third-party dependencies beyond three pip packages.

✦

Aesthetic scoring

Apple's VNCalculateImageAestheticsScoresRequest scores composition, lighting, and visual appeal. Utility images (screenshots, documents) are automatically flagged and filtered.

⊗

Duplicate detection

Feature embedding similarity clusters near-identical shots. Configurable cosine similarity threshold (default 0.92). Best-scoring image from each cluster advances; others are logged as rejects.

◈

Scene classification

1000+ label classification via VNClassifyImageRequest. Filter selects by label: --tags flower,indoor,table. Classification data is always in the report even without filtering.

◉

Subject-aware palettes

Foreground instance masking extracts a subject color palette independent of the scene background. Two palettes per image: subject_colors (arrangement, product) and dominant_colors (full frame).

▦

HTML contact sheet

Generate an interactive grid of your selects with score bars, hover-revealed palettes, classification labels, and a lightbox with keyboard navigation. Self-contained single HTML file.

◎

JSON report

Full structured output: aesthetic scores, quality flags, classification labels with confidence, color palettes, duplicate cluster IDs, select/reject reasoning. Designed for downstream processing.

Install & Run

Three pip packages. That's it.

No model downloads. No API keys. No Docker. Requires macOS 15+ on Apple Silicon.

# Clone and install
git clone https://github.com/echase/VisionCull.git
cd VisionCull
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Basic run — score and copy top 40 selects
python3 visioncull.py ~/Photos/shoot/ --output ~/selects/

# Full pipeline — deduplicate, classify, subject analysis
python3 visioncull.py ~/Photos/shoot/ \
  --output ~/selects/ \
  --selects 40 \
  --duplicates --threshold 0.92 \
  --subject \
  --report report.json \
  --rank-prefix

# Generate HTML contact sheet from report
python3 contact_sheet.py --report report.json
